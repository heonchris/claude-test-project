# 족저압 인솔 앱 (모바일 UI 프로토타입)

실제 앱처럼 동작하는 화면. 데스크탑에서는 휴대폰 기기 프레임 안에서,
휴대폰에서는 화면 전체를 채우며 구동된다.

공개 링크: https://claude.ai/code/artifact/091cacae-293b-46f2-bb74-34120a9716cb

`app/demo/` 는 같은 엔진의 대시보드(넓은 화면) 버전이다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 측정 | 양발 히트맵, 무게중심, 좌우·전후 균형 게이지, 지표 3종, 압력 추이 |
| 기록 | 저장된 세트 목록. 항목을 누르면 리포트가 올라온다 |
| 설정 | 시연 시나리오 선택, 기기 정보 |

리포트는 측정 정지 시 자동으로 올라오는 시트 형태이며, 기록 탭에서 다시 열 수 있다.

## 반응형 분기

`520px` 를 기준으로 갈린다.

- **초과** — 390×844 기기 프레임, 베젤·다이내믹아일랜드·상태바 표시
- **이하** — 프레임을 벗고 전체화면. 상태바는 실제 기기 것을 쓰므로 감추고
  `env(safe-area-inset-*)` 로 노치·홈 인디케이터를 피한다

## 실제 센서로 교체할 때

`simulate()` 함수만 BLE 수신 데이터로 바꾸면 된다.
`vals.L[0..7]`, `vals.R[0..7]` 에 0~1023 값을 넣으면 나머지는 그대로 동작한다.

## 한계

- 시뮬레이션 데이터. 실제 FSR의 비선형성·히스테리시스는 반영되지 않음
- 기록은 메모리에만 저장되어 새로고침하면 사라짐 (실제 앱은 DB 필요)
- 판정 기준값은 임시값이며 실측 데이터로 재조정 필요
- 의학적 진단이 아닌 운동 자세 피드백 범위로 문구를 한정함
