# 냥집사 🐈‍⬛

사진 한 장과 탭 몇 번으로 오늘의 **식단·물·운동**을 남기면, 고양이가 벽을 타고 올라가는
**나 혼자 쓰는** 기록 앱.

- 로그인 없음, 서버 없음, 비용 없음. 기록은 이 폰을 떠나지 않습니다.
- 비행기 모드에서도 100% 동작합니다.
- 못 채운 날에 앱이 나를 탓하지 않습니다. 고양이는 그냥 낮잠을 잡니다.

자세한 기준은 [SPEC.md](./SPEC.md)에 있습니다.

## 자주 쓰는 명령어

| 하고 싶은 것 | 명령어 |
|---|---|
| 아이폰에 설치 / 7일마다 갱신 | `npm run iphone` |
| 맥 안의 시뮬레이터로 보기 | `npm run xcode` |
| Expo Go로 열기 (QR) | `npm start` |
| 폰과 맥이 다른 와이파이일 때 | `npm run tunnel` |
| 고양이 모양 미리보기 · 아이콘 다시 만들기 | `python3 tools/render_assets.py` |

## 고양이 모양 고치기

고양이는 그림 파일이 아니라 **코드로 그린 도형**(`components/Cat.tsx`)이라 말로 고칠 수 있습니다.

- `눈을 더 크게 해줘` · `꼬리를 더 길고 가늘게` · `귀를 더 뾰족하게`
- **한 번에 하나씩** 부탁해야 원하는 방향으로 갑니다

`python3 tools/render_assets.py`를 돌리면 `tools/cat-preview.png`에 5가지 상태가 한 장으로 나옵니다.
앱을 켜지 않고도 모양을 확인할 수 있습니다.

## 기록 백업 (중요)

서버가 없어서 **기록을 복구해줄 곳이 없습니다.**
설정 탭 → `데이터 내보내기` → JSON 파일을 어딘가에 남겨두세요.

## 막혔을 때

빨간 에러 글씨를 **전부 복사해서** 클로드 코드에 붙여넣고 `이 에러 고쳐줘` 라고 하면 됩니다.
자주 나는 오류는 [SPEC.md 9-3](./SPEC.md#9-3-겪은-문제와-해결)에 정리돼 있습니다.
