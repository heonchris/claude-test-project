# 냥집사 🐈‍⬛

사진 한 장과 탭 몇 번으로 오늘의 **식단·물·운동**을 남기면, 고양이가 벽을 타고 올라가는
**나 혼자 쓰는** 기록 앱.

- 로그인 없음, 서버 없음, 비용 없음. 기록은 이 폰을 떠나지 않습니다.
- 비행기 모드에서도 100% 동작합니다.
- 못 채운 날에 앱이 나를 탓하지 않습니다. 고양이는 그냥 낮잠을 잡니다.

자세한 기준은 [SPEC.md](./SPEC.md)에 있습니다.

---

## 폰에서 실행하기

처음 한 번만 하면 됩니다.

**1. 준비물**

| 항목 | 설명 |
|---|---|
| Node.js LTS | https://nodejs.org 에서 LTS 버전 설치 |
| 스마트폰 | 앱스토어/플레이스토어에서 **Expo Go** 앱 설치 |

**2. 터미널에서 이 폴더로 간 뒤, 세 줄**

```bash
npm install
npx expo start
```

**3. 터미널에 뜬 QR코드를 폰의 Expo Go로 스캔**

끝입니다. 폰에서 바로 앱이 열립니다.
코드를 고치면 폰 화면이 알아서 새로고침됩니다.

> 막혔을 때는 빨간 에러 글씨를 **전부 복사해서** 클로드 코드에 붙여넣고 `이 에러 고쳐줘` 라고 하면 됩니다.

## 고양이 모양이 마음에 안 들 때

고양이는 그림 파일이 아니라 **코드로 그린 도형**이라서, 말로 고칠 수 있습니다.
`components/Cat.tsx` 한 파일이 전부입니다.

- `눈을 더 크게 해줘`
- `꼬리를 더 길고 가늘게`
- `귀를 더 뾰족하게`
- `발톱 자국을 더 짧게`

**한 번에 하나씩** 부탁해야 원하는 방향으로 갑니다.

앱을 켜지 않고 모양만 확인하고 싶으면:

```bash
python3 tools/render_assets.py
```

`tools/cat-preview.png`에 5가지 상태(자는 중 / 깨어남 / 매달림 / 꼭대기 / 놀람)가 한 장으로 나옵니다.
앱 아이콘과 스플래시도 이 스크립트가 같이 다시 만듭니다.

## 플랜 붙여넣기

1. **플랜** 탭에서 `AI에게 보낼 프롬프트 복사`를 누릅니다.
2. 쓰는 챗봇에 붙여넣고, `[내 조건: ...]` 부분만 내 얘기로 바꿔서 보냅니다.
3. 답으로 온 내용을 통째로 복사해서, 플랜 탭의 붙여넣기 칸에 넣고 `이 플랜 시작하기`.

JSON이 아니어도 괜찮습니다. 형식이 안 맞으면 **줄 단위 체크리스트**로 저장됩니다.
붙여넣은 원문은 어떤 경우에도 그대로 보관됩니다.

## 폴더 구조

```
app/            화면 (expo-router: 파일 하나 = 화면 하나)
  (tabs)/       오늘 · 기록 · 플랜 · 설정
  add/          식단/운동 추가 모달
components/     고양이, 링, 물컵, 버튼 같은 조각들
db/             SQLite 스키마와 질의문
lib/            날짜, 사진 저장, 플랜 파서, 백업, 알림
theme/          색과 글씨 (SPEC 7번)
tools/          아이콘·미리보기 생성 스크립트
assets/         폰트, 아이콘
```

## 만들면서 알아두면 좋은 것

- **기록은 이 폰에만 있습니다.** 폰을 바꾸거나 앱을 지우면 사라집니다.
  설정 → `데이터 내보내기`로 가끔 JSON 파일을 남겨두세요. (사진 파일은 백업에 담기지 않습니다)
- 이 앱은 개인 기록용입니다. 의학적 조언이나 진단을 하지 않습니다.
  체중·영양 목표는 필요하면 전문가와 상의해서 정하는 게 좋습니다.
