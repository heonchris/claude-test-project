# 인물 사진 1차 셀렉 도구

한 번 촬영에 700~1000장씩 나오는 인물 사진에서 **볼 필요조차 없는 컷**을 자동으로 치워주는
맥(애플 실리콘) 전용 로컬 도구입니다.

- 전부 내 맥 안에서 돌아갑니다. **인터넷 업로드 없음, 유료 API 없음.**
  (최초 1회 얼굴 인식 모델 약 5MB만 내려받고, 그 뒤로는 인터넷 없이 동작합니다)
- **원본 파일을 절대 건드리지 않습니다.** 이동·삭제·수정 없이 판정 결과만 따로 만듭니다.
- AI가 "좋은 사진"을 고르지 않습니다. **명백히 못 쓸 컷과 중복 컷만 치웁니다.**
  최종 선택은 사람이 합니다.

---

## 0. 이 도구가 하는 일 / 못 하는 일

| 해주는 것 | 못 하는 것 |
|---|---|
| 초점 나간 컷 걸러내기 (얼굴 기준) | 표정이 좋은지 나쁜지 판단 |
| 눈 감은 컷 걸러내기 | 구도가 좋은지 판단 |
| 연사에서 같은 장면 묶고 대표 1장 뽑기 | 누가 주인공인지 판단 |
| 노출 문제 표시 (탈락이 아니라 '주의') | 감정·분위기 평가 |
| 별점을 매겨 라이트룸으로 넘기기 | 사람 대신 최종 셀렉 |

**1,000장을 한 장씩 보는 대신, 200~300개 그룹의 대표 컷만 보시게 됩니다.**

## 1. 설치 (터미널에 그대로 붙여넣기)

터미널은 `Command + Space` → "터미널" 입력 → 엔터로 엽니다.

### 1-1. 파이썬이 있는지 확인

```bash
python3 --version
```

- `Python 3.9` 이상이 나오면 그대로 진행하세요.
- "command not found"가 뜨거나 개발자 도구 설치 창이 뜨면, 창의 **[설치]** 를 누르고
  10분쯤 기다린 뒤 위 명령을 다시 실행하세요.
- 그래도 안 되면 <https://www.python.org/downloads/macos/> 에서 최신 버전을 설치하세요.

### 1-2. 도구 폴더로 이동

`portrait-culler` 폴더를 원하는 위치(예: 서류 폴더)에 두고, 터미널에서 그 폴더로 이동합니다.
터미널에 `cd ` (cd + 한 칸 띄우기)를 입력한 뒤, **폴더를 터미널 창으로 끌어다 놓고** 엔터를 치면 됩니다.

```bash
cd ~/Documents/portrait-culler     # 예시입니다. 실제 경로로 바꾸세요
```

### 1-3. 가상환경 만들기 + 라이브러리 설치

가상환경은 이 도구가 쓰는 라이브러리를 맥의 다른 곳과 분리해 담아두는 상자입니다.
맥 시스템을 건드리지 않으므로 안전하고, 나중에 폴더째 지우면 완전히 삭제됩니다.

```bash
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

마지막 명령은 2~5분 걸립니다. 터미널 줄 앞에 `(venv)`가 붙으면 성공입니다.

> **중요:** 터미널을 새로 열 때마다 `cd` 로 폴더에 들어간 뒤
> `source venv/bin/activate` 를 한 번씩 실행해야 합니다.

### 1-4. 얼굴 인식 모델 내려받기 (최초 1회, 약 5MB)

```bash
python cull.py setup
```

### 1-5. 설치 확인

```bash
python cull.py check
```

모든 항목에 `[O]`가 뜨고 마지막에 `준비 완료입니다.`가 나오면 끝입니다.

## 2. 사용법 — 단계별로 확인하며 진행하기

처음에는 **반드시 사진 복사본 폴더**로 테스트하세요.
(원본을 건드리지 않도록 만들었지만, 첫 실행은 복사본이 마음 편합니다.)

각 단계는 사진 10장만 보고 결과를 눈으로 확인할 수 있게 되어 있습니다.
`--limit 10` 은 "앞에서 10장만"이라는 뜻이고, 빼면 전부 처리합니다.

폴더 경로는 직접 타이핑하지 말고 **폴더를 터미널로 끌어다 놓으면** 자동으로 입력됩니다.

### 단계 2 — 사진이 제대로 열리는지

```bash
python cull.py test-load /사진/폴더/경로 --limit 10
```

- RAW를 **내장 미리보기**로 읽었는지(`RAW 내장 미리보기`), 축소 디코딩으로 폴백했는지 표시됩니다.
- 촬영시각을 제대로 읽었는지 확인하세요.
- `_cull/test_load` 폴더에 썸네일이 생깁니다. **세로 사진이 바로 서 있는지** 꼭 확인하세요.
  (누워 있으면 얼굴 검출이 안 됩니다)

### 단계 3 — 얼굴을 찾고 초점을 재는지

```bash
python cull.py test-face /사진/폴더/경로 --limit 10
```

- `_cull/test_face` 폴더에 **초록 상자**가 그려진 이미지가 생깁니다. 상자가 진짜 얼굴에 맞는지 보세요.
- `얼굴선명도`가 핵심 수치입니다. 화면 전체가 아니라 **가장 큰 얼굴 영역**에서 잰 값입니다.
- 멀쩡한 사진이 `초점흐림(탈락)`으로 나오면 → `photo_cull/config.py`의 `SHARP_REJECT`를 낮추세요.

### 단계 4 — 눈 감음 판정

```bash
python cull.py test-eyes /사진/폴더/경로 --limit 10
```

- `_cull/test_eyes` 폴더에 눈 landmark(점)가 찍힌 얼굴 크롭이 저장됩니다. 점이 눈 위에 정확히 있는지 보세요.
- `EAR` 값이 작을수록 감은 눈입니다. `깜빡임`은 0~1이고 클수록 감은 눈입니다.
- 얼굴이 너무 작으면(기본: 화면 긴 변의 7% 미만) 오판이 많아 **판정을 건너뜁니다**(`판정불가`).
- 판정 기준은 EAR과 깜빡임 점수 **둘 다** '감음'일 때만 감음입니다(오탈락을 줄이기 위해).
  더 적극적으로 걸러내려면 `config.py`의 `EYE_DECISION_MODE`를 `"any"`로 바꾸세요.

### 단계 5 — 연사 그룹핑

```bash
python cull.py test-group /사진/폴더/경로 --limit 50
```

- 촬영시각이 3초 이내로 이어지고 + 그림이 비슷하면 같은 그룹으로 묶습니다.
- 그룹 안에서 점수가 가장 높은 컷에 `★`(그룹대표)가 붙습니다.
- 다른 장면이 한 그룹에 섞였으면 → `PHASH_MAX_DISTANCE`를 낮추세요.
- 같은 연사가 여러 그룹으로 쪼개졌으면 → `BURST_GAP_SEC` 또는 `PHASH_MAX_DISTANCE`를 높이세요.

### 단계 6·7 — 전체 실행

```bash
python cull.py run /사진/폴더/경로
```

끝나면 사진 폴더 안에 `_cull` 폴더가 생기고, 그 안에 결과물 3종이 들어 있습니다.

| 파일 | 용도 |
|---|---|
| `report.html` | 브라우저로 열어 그룹별 비교 (출력 B) |
| `result.csv` | 엑셀로 열어 수치 확인 · 임계값 튜닝용 (출력 C) |
| `*.xmp` (사진 옆) | 라이트룸용 별점 사이드카 (출력 A) |
| `cache.json` | 분석 결과 캐시 (지우면 처음부터 다시 분석) |
| `errors.log` | 읽기 실패한 파일 목록 |

**자주 쓰는 옵션**

```bash
python cull.py run /폴더 --limit 100      # 앞에서 100장만 (시험 실행)
python cull.py run /폴더 --no-xmp         # 사이드카 만들지 않고 리포트만
python cull.py run /폴더 --overwrite-xmp  # 이미 있는 .xmp를 덮어씀 (기본은 건너뜀)
python cull.py run /폴더 --dry-run        # 사이드카를 실제로 쓰지 않고 결과만 확인
python cull.py run /폴더 --links          # 별점별 바로가기 폴더도 생성
python cull.py run /폴더 --jobs 4         # 사용할 CPU 코어 수 (기본 자동)
python cull.py run /폴더 --no-cache       # 캐시 무시하고 전부 다시 분석
```

## 3. 라이트룸으로 넘기기

### RAW로 촬영한 경우 (CR2/CR3/NEF/ARW/RAF …)

1. 라이트룸 클래식에서 해당 폴더를 가져오기(Import)
2. 반영할 사진을 전체 선택 (`Command + A`)
3. 메뉴 **[메타데이터] → [파일에서 메타데이터 읽기]**
   (영문판: Metadata → Read Metadata from File)
4. "메타데이터를 덮어쓰시겠습니까?" → 확인
5. 라이브러리 필터에서 **별 1개 이상**만 남기고 셀렉 시작

별점 규칙은 이렇습니다.

| 상태 | 별점 | 라벨 |
|---|---|---|
| 그룹대표 + 문제 없음 | ★★★ | — |
| 문제 없지만 그룹대표 아님 | ★ | — |
| 초점흐림 / 눈감음 | ☆ (0) | `Reject` |
| 얼굴 없는 컷 (풍경·소품) | ★ | — |

태그는 키워드로도 들어갑니다(`AI_눈감음`, `AI_초점흐림`, `AI_그룹대표` …).
라이트룸 키워드 목록에서 바로 필터할 수 있습니다.

### JPEG으로 촬영한 경우 — 주의

**라이트룸 클래식은 JPEG에는 .xmp 사이드카를 읽지 않습니다.**
(사이드카는 RAW 전용이고, JPEG은 파일 안에 직접 써야 하는데 이 도구는 원본을 건드리지 않습니다.)

JPEG 촬영분은 이렇게 쓰세요.

- `report.html`로 그룹별 훑어보기 (가장 편합니다)
- `python cull.py run /폴더 --links` 로 별점별 **바로가기 폴더**를 만들어 파인더에서 보기
  (`_cull/links/3star_대표`, `1star_보류`, `0star_탈락` — 원본을 복사·이동하지 않는 심볼릭 링크입니다)
- `result.csv`를 엑셀로 열어 파일명 목록으로 활용

## 4. 임계값 튜닝 — 이게 핵심입니다

처음 돌리면 판정이 본인 취향과 안 맞습니다. 초점 기준이 너무 엄격해 쓸 만한 컷을 버리거나,
반대로 너무 느슨할 수 있습니다. **첫 실행 후 반드시 해야 할 일:**

1. `_cull/result.csv`를 엑셀/넘버스로 엽니다.
2. "이건 잘못 걸렀다" 싶은 사진을 찾아 그 줄의 수치를 봅니다.
3. `photo_cull/config.py`를 텍스트 편집기로 열어 해당 값을 고칩니다.
4. 다시 실행합니다. **측정값은 캐시되므로 임계값만 바꾼 재실행은 몇 초면 끝납니다.**

두세 번 반복하면 본인 촬영 스타일에 맞아떨어집니다.

| 증상 | 고칠 값 | 방향 |
|---|---|---|
| 쓸 만한 컷이 `초점흐림`으로 탈락 | `SHARP_REJECT` (기본 55) | 낮춘다 (예: 35) |
| 흐린 컷이 살아남음 | `SHARP_REJECT` | 높인다 (예: 80) |
| 눈 뜬 사진이 `눈감음`으로 탈락 | `EAR_CLOSED` (기본 0.18) | 낮춘다 (예: 0.15) |
| 눈 감은 사진이 안 걸림 | `EAR_CLOSED` | 높인다 (예: 0.20) |
| 눈 감음을 더 적극적으로 잡고 싶음 | `EYE_DECISION_MODE` | `"both"` → `"any"` |
| 그룹이 너무 잘게 쪼개짐 | `PHASH_MAX_DISTANCE` (기본 12) | 높인다 (예: 16) |
| 다른 장면이 한 그룹에 섞임 | `PHASH_MAX_DISTANCE` | 낮춘다 (예: 8) |
| 연사 묶음이 끊김 | `BURST_GAP_SEC` (기본 3.0) | 높인다 (예: 5.0) |
| 노출 주의가 너무 많이 뜸 | `HIGHLIGHT_WARN_RATIO` / `SHADOW_WARN_RATIO` | 높인다 |
| 초점보다 눈 뜸을 더 중시하고 싶음 | `W_SHARP` / `W_EYE` | 가중치 조정 (합 1.0) |

> `config.py`에서 **분석 항목 자체**(분석 크기, 얼굴 신뢰도 등)를 바꿨다면
> 파일 맨 위 `ANALYSIS_VERSION`의 숫자를 1 올려주세요. 캐시를 버리고 다시 분석합니다.
> 임계값·가중치만 바꿨다면 그대로 두면 됩니다(재실행이 훨씬 빠릅니다).

## 5. 처리 시간

같은 컨테이너(4코어 중 3개 사용)에서 실제로 측정한 값입니다.

| 종류 | 실측 속도 | 1000장 환산 |
|---|---|---|
| 24MP JPEG (약 2MB) | 4.5장/초 | 약 3분 40초 |
| 12MP RAW (NEF 10MB, 내장 미리보기 사용) | 5.0장/초 | 약 3분 20초 |
| 캐시 재사용(임계값만 변경) | — | **수 초** |

맥(M1/M2/M3)에서는 코어를 더 쓰므로 비슷하거나 더 빠릅니다. 다만 실제 촬영분은

- RAW 파일이 더 크고(45MP면 50~80MB)
- 외장 SSD나 메모리카드에서 읽으면 디스크 속도가 병목입니다

**현실적인 예상: 1000장 기준 5~15분.** 외장 디스크에서 대용량 RAW를 읽으면 20분까지 갈 수 있습니다.
(내장 SSD로 복사한 뒤 돌리면 훨씬 빠릅니다)

## 6. 검증된 동작 / 알려진 한계

실제 인물 사진으로 검증한 결과입니다.

**잘 되는 것**

- RAW 내장 JPEG 미리보기 추출 (실제 니콘 NEF로 확인)
- EXIF 회전 정보가 있는 세로 사진 자동 교정
- 초점: 선명한 얼굴 780~800 vs 흐린 얼굴 4~6 — 확실하게 갈립니다
- 얼굴 검출: 얼굴이 **화면 긴 변의 4% 이상**이면 찾습니다.
  (전체 화면에서 못 찾으면 화면을 4조각으로 나눠 다시 찾습니다. 전신 샷도 대체로 잡힙니다)
- 눈 감음: 정면 얼굴은 정확합니다.
  실측 분포 — 눈 뜸 EAR 0.190~0.329 / 눈 감음 0.007~0.169, 깜빡임 점수는 뜸 0.05~0.30 / 감음 0.32~0.76
- **눈 뜬 사진 21장 중 감았다고 잘못 탈락시킨 경우: 0건** (가장 중요한 성질입니다)
- 실제 눈감은 인물 사진 12장 테스트: 7장 감지, 1장은 한쪽 눈만 감아 통과(설계대로),
  4장은 각도가 심하거나 얼굴이 작아 `판정불가` 처리 — **잘못 탈락시킨 사진 없음**
- 얼굴 오검출 방어: 고양이 사진, 가구를 얼굴로 잡은 오검출을 landmark 검증으로 걸러냄
- 파일이 깨져 있어도 그 파일만 건너뛰고 전체는 계속 진행

**한계 (알고 쓰셔야 합니다)**

- **옆얼굴·고개를 크게 젖힌 얼굴의 눈 감음은 놓치거나 판정불가가 됩니다.**
  놓치는 쪽(사진이 살아남음)으로 설계했습니다. 멀쩡한 사진을 버리는 것보다 낫기 때문입니다.
- **눈 감음 임계값의 여유가 크지 않습니다.** 뜬 눈 최저 0.190 / 감은 눈 최고 0.169 사이의
  0.18을 기본값으로 잡았습니다. 촬영 스타일(눈매, 조명, 화각)에 따라 다를 수 있으니
  첫 실행 후 CSV의 `EAR좌/EAR우`, `깜빡임좌/깜빡임우` 열을 꼭 확인하고 조정하세요.
- **점수는 같은 그룹 안에서 비교하세요.** 라플라시안 선명도는 사진의 내용에 따라 절대값이
  달라서(어떤 장면은 800, 어떤 장면은 240이 '선명함'), 다른 장면끼리의 점수 비교는 의미가 약합니다.
  같은 그룹 안에서는 동점일 때 원본 선명도 수치로 대표를 정하므로 정확합니다.
- 한쪽 눈만 감은 컷은 기본 설정에서 '눈 뜸'입니다(양쪽 다 감겨야 탈락).
  바꾸려면 `EYE_CLOSED_REQUIRED_EYES = 1`.
- 새까맣거나 새하얗게 날아간 얼굴은 초점 판정이 불가능합니다(`초점판정불가`로 표시하고
  초점 때문에 탈락시키지는 않습니다).
- 얼굴이 화면 대비 7% 미만인 전신·원거리 컷은 (검출은 되어도) 눈 판정을 건너뜁니다.
- 표정의 좋고 나쁨은 판단하지 못합니다. 그건 사람 몫입니다.
- **맥에서 직접 실행한 검증은 아직 못 했습니다.** 개발·검증은 리눅스 컨테이너에서 했고,
  애플 실리콘용 라이브러리가 모두 제공되는 것은 확인했습니다.
  처음 실행할 때 `python cull.py check`가 통과하는지부터 확인해 주세요.

## 7. 문제가 생기면

**`command not found: python`**
→ `source venv/bin/activate` 를 실행했는지 확인하세요. 줄 앞에 `(venv)`가 있어야 합니다.

**`python cull.py check` 에서 mediapipe가 `[X]`**
→ `pip install mediapipe` 를 다시 실행하세요. 애플 실리콘용 휠이 정상 제공됩니다.
설치되지 않아도 얼굴 검출은 OpenCV로 대체 동작하지만, **눈 감음 판정은 전부 '판정불가'가 됩니다.**

**모델 다운로드 실패**
→ `python cull.py setup`이 알려주는 두 개의 주소를 브라우저로 열어 파일을 받은 뒤
`portrait-culler/models/` 폴더에 넣으세요.

**RAW가 `RAW 축소 디코딩`으로 표시되고 느림**
→ 그 기종은 내장 미리보기가 없거나 너무 작다는 뜻입니다. 정상 동작이며 속도만 느려집니다.
`config.py`의 `MIN_PREVIEW_LONG_SIDE`를 낮추면 작은 미리보기도 그냥 쓰게 할 수 있습니다.

**얼굴을 못 찾는 사진이 많음**
→ ① 단계 2 썸네일에서 세로 사진이 누워 있는지 확인하세요(누워 있으면 얼굴을 못 찾습니다)
→ ② `python cull.py check`에서 `얼굴 검출 모델`이 `blaze_face_full_range`인지 확인하세요.
  `short_range`로 나오면 원거리 얼굴을 못 찾습니다 → `python cull.py setup`을 다시 실행
→ ③ `FACE_MIN_CONFIDENCE`를 0.5 → 0.4로 낮춥니다(오검출이 늘 수 있습니다)
→ 참고: `ANALYZE_LONG_SIDE`를 키워도 검출률은 거의 오르지 않습니다.
  검출 모델은 '화면에서 얼굴이 차지하는 비율'로 판단하기 때문입니다.
  대신 화면을 조각내 다시 찾는 기능(`RETRY_TILED_WHEN_NO_FACE`)이 그 역할을 합니다.

**터미널 로그를 자세히 보고 싶을 때**
→ `PORTRAIT_CULLER_VERBOSE=1 python cull.py run /폴더`

**결과를 완전히 초기화하고 싶을 때**
→ 사진 폴더 안의 `_cull` 폴더를 통째로 지우세요. 원본과는 무관합니다.
사이드카까지 지우려면 사진 폴더의 `*.xmp` 파일을 지우면 됩니다.

## 8. 폴더 구조

```
portrait-culler/
├── cull.py                 ← 실행 파일 (python cull.py ...)
├── requirements.txt        ← 필요한 라이브러리 목록
├── models/                 ← 얼굴 인식 모델 (setup으로 자동 생성)
└── photo_cull/
    ├── config.py           ← ★ 튜닝은 전부 여기서
    ├── imageload.py        ← 단계2: RAW 미리보기 추출 / 이미지 로딩
    ├── faces.py            ← 단계3~4: 얼굴 검출 + 눈 landmark
    ├── metrics.py          ← 선명도 / 노출 / 그림지문 측정
    ├── analyze.py          ← 사진 1장 분석 (측정 담당)
    ├── grouping.py         ← 단계5: 연사 그룹핑
    ├── scoring.py          ← 단계6: 점수 · 태그 · 별점 (판정 담당)
    ├── cache.py            ← 재실행 시 건너뛰기
    ├── runner.py           ← 여러 코어로 나눠 실행 + 진행률
    ├── out_xmp.py          ← 출력 A: XMP 사이드카
    ├── out_html.py         ← 출력 B: HTML 리포트
    ├── out_csv.py          ← 출력 C: CSV
    └── cli.py              ← 명령어 처리
```

측정(analyze)과 판정(scoring)을 일부러 분리했습니다. 그래서 임계값을 바꿔 다시 돌릴 때
사진을 다시 읽지 않고 몇 초 만에 끝납니다.
