# Card

본문 카드 한 장(1080 × 1350): 소제목 하나, 문단 3~5개, 결론 한 줄.

**넘기는 것**: `label`(`02 <소제목 요약>`), `heading`, `paragraphs`(문자열 또는 노드 배열, 문자열 안 `\n`은 줄바꿈), `conclusion`, 선택 `sticker`(`Sticker` props).

- 생각이 바뀌는 단락마다 한 장. 본문은 공백 포함 약 250자까지.
- 넘치면 다음 카드로 이어 붙이지 말고 단락을 다시 나눠 새 카드에 자기 소제목을 준다.
- `Strong`은 한 문단에 한 곳.
- `sticker`는 본문이 짧아 오른쪽 아래가 비어 있을 때만.
