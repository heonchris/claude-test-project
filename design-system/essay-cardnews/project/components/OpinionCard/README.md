# OpinionCard

정리 카드(1080 × 1350): 덱의 마지막 장. Tag, 질문형 소제목, 본문, 인용 박스, 오른쪽 정렬 마무리 두 줄.

**넘기는 것**: `label`, `tag`(기본 "in my opinion"), `heading`(질문형), `paragraphs`, `quote`(명조로 들어갈 한두 줄), 선택 `quoteCite`, `closing`(두 줄 배열, 보통 두 번째 줄이 "여러분은 어떻게 생각하시나요").

- 검정 `Tag`가 나오는 유일한 카드.
- 여기서 한 번만 독자에게 말을 건다.
