# Figure

이미지와 출처. `kind="capture"`는 900 폭 원본 비율, `kind="hero"`는 900 × 675.

**넘기는 것**: `kind`, `src`, `alt`, `ratio`(캡처의 가로/세로, 기본 16/9), `source`(예: "[출처 - Youtube 조승연의 탐구생활]"), 선택 `placeholder` 문구.

- 출처는 `caption` 24px `ink-muted`, 가운데 정렬, 이미지 바로 아래.
- `src`가 없으면 크기를 적은 회색 자리가 생긴다.
- 대표 이미지는 표지에서만. 모서리는 직각.
