# CoverCard

표지 카드 한 장(1080 × 1350): 여는 문장, 작성자, 구분선, 출발점 이미지, 도입 두세 줄.

**넘기는 것**: `title`(글의 첫 문장이나 여는 한 문장, `\n`으로 줄바꿈, 두 줄까지), `author`(`AuthorRow` props), `figure`(`Figure` props), `intro`(문자열 또는 문자열 배열, 두세 줄), `label`(기본 `01 표지`).

- 표지를 넣을지는 매번 사용자에게 먼저 묻는다.
- `author`는 `{ name: "우승헌", avatarSrc: <Profile의 avatar.png> }`.
- `figure`는 사용자가 이미지를 줬을 때만 넘긴다. 없으면 빼고, 빈 자리를 두지 않는다.
- 대표 이미지(900 × 675)와 함께면 제목 두 줄, 도입 두 줄까지. 16:9 캡처면 도입 세 줄까지.
- 제목은 원문 문장 그대로. 요약하거나 새로 짓지 않는다.
- 덱의 첫 장, 한 번만.
