사용자가 쓴 글을 받아 인스타그램 세로 카드뉴스(1080 × 1350)로 옮기는 시스템. 흰 바탕에 검정 글자, 소제목에만 민트 형광펜을 긋는 담백한 에세이 노트 스타일이다. **디자인보다 글이 먼저 읽혀야 한다.**

컴포넌트는 `window.CardNews`(`components/bundle.js`)에 있고, 스타일은 `components/bundle.css`의 `.cn-*` 클래스다. 카드 한 장은 `.cn-card` 하나(1080 × 1350)이며 나머지는 모두 그 안에 들어간다.

## 글을 카드로 나누는 방법

받은 글을 아래 순서로 카드에 옮긴다. **글의 내용과 문장은 바꾸지 않는다.** 나누고, 줄을 바꾸고, 강조할 곳만 고른다.

1. **표지 `CoverCard`** — 1장. 글의 첫 문장이나 전체를 여는 한 문장을 `cover-title`로. 그 아래 `AuthorRow`, 구분선, 글이 무엇에서 시작됐는지(`Figure kind="capture"` + 출처, 또는 `Figure kind="hero"`)와 도입 두세 줄.
2. **본문 카드 `Card`** — 생각이 바뀌는 단락마다 1장. 맨 위에 `Heading` 하나, 그 아래 `BodyText`, 마지막에 그 카드의 결론 한 줄 `Conclusion`.
3. **생각 카드 `ThoughtCard`** — 필요할 때만. 글의 핵심 질문 한두 문장을 `statement`로 카드 가운데에 크게, 마지막에 독자에게 묻는 한 줄을 `emphasis`로.
4. **정리 카드 `OpinionCard`** — 마지막 1장. `Tag`("in my opinion") → 질문형 소제목 → 본문 → `QuoteBox` → 오른쪽 정렬 마무리 두 줄.

### 나누는 기준

- 카드 한 장의 본문은 문단 3~5개, 공백 포함 약 250자까지. 넘치면 소제목을 유지한 채 다음 카드로 넘기지 말고, 단락을 다시 나눠 각 카드에 자기 소제목을 준다.
- 소제목은 그 단락이 답하는 질문이나 시점으로 짓는다: "그럼 이 생각은 어디서 왔는가?", "언제 생각이 변했는가?", "이걸 처음 생각했던 순간은 전역한 직후이다". 원문에 소제목이 없으면 원문의 문장에서 뽑는다.
- 단어 중간에서 줄이 끊기지 않게 한다. `.cn-card`에 `word-break: keep-all`이 들어 있다.
- 줄바꿈은 의미 단위로 직접 넣는다(문자열 안의 `\n`). 한 줄에 한 생각.
  > 겨우 그거 하나 다녀온다고 인생이 변하지도 않을 거고,
  > 취업에 도움이 되지도 않을 거고
- 본문 카드는 6~8장을 넘기지 않는다. 표지 + 본문 + 정리까지 보통 5~8장.
- 카드 이름 `data-screen-label`(각 카드의 `label` prop)은 번호 + 짧은 이름: `01 표지`, `02 전역 직후`.

## 문체

- 글쓴이 한 사람의 1인칭 독백체, 반말 서술("~했다", "~것 같다", "~일 수도 있겠다"). 원문 문체를 그대로 따른다.
- 마지막에 독자에게 한 번 말을 건다: "여러분은 어떻게 생각하시나요".
- 이모지, 느낌표 남발, 해시태그를 카드 안에 넣지 않는다.
- 맞춤법·띄어쓰기만 고치고, 말투와 말끝은 원문 그대로 둔다.

## 시각 기초

### 색

| 토큰 | 쓰는 곳 |
| --- | --- |
| `paper` | 모든 카드의 바탕. 언제나 흰색. |
| `ink` | 제목, 소제목, 강조(`.cn-strong`), 결론, `statement`, `emphasis`, 인용 박스 테두리, `Tag` 바탕 |
| `ink-body` | 본문 문단 |
| `ink-muted` | 보조 정보: 출처, 작성자 핸들, 자리 표시 글자 |
| `mint` | **소제목 뒤 형광펜(`.cn-mark`) 단 한 곳.** 본문 강조에 쓰지 않는다. |
| `line` | 표지 구분선 1px |
| `placeholder` | 이미지가 아직 없을 때의 자리 바탕 |

검정 `Tag`는 정리 카드에서만 쓴다.

### 글꼴

전부 Nanum Gothic(`sans`) 한 가족. 명조(`serif`, Nanum Myeongjo)는 `QuoteBox` 안 인용구에만. Georgia·Helvetica·Times 같은 영문 글꼴을 섞지 않는다. 두 글꼴 모두 Google Fonts에서 불러온다(`bundle.css` 첫 줄).

### 글자 크기

정해진 단계만 쓴다. 24px보다 작은 글자는 없다.

| 스타일 | 크기 | 굵기 | 쓰는 곳 |
| --- | --- | --- | --- |
| `cover-title` | 76 | 800 | 표지 제목 |
| `heading` | 56 | 800 | 카드 소제목 |
| `quote` | 50 | 700 serif | 인용 박스 |
| `statement` | 42 | 700 | 생각 카드 가운데 |
| `emphasis` | 36 | 700 | 생각 카드 마지막 질문 |
| `meta` | 30 | 700 | 작성자 이름 |
| `body` | 28 | 400 | 본문 |
| `body-strong` | 28 | 800 | 문단 속 강조, 결론, 정리 카드 마무리 |
| `label` | 28 | 700 | `Tag` |
| `caption` | 24 | 400 | 출처, 핸들, 자리 표시 |

본문 안의 핵심 구절은 크기를 키우지 말고 `Strong`(`.cn-strong`, 굵기 800 + `ink`)으로만 강조한다. 한 문단에 한 곳.

### 정렬

소제목과 본문은 왼쪽 정렬. 결론 한 줄, `statement`, 마무리 질문, 출처는 가운데 정렬. 정리 카드의 마지막 두 줄만 오른쪽 정렬.

### 여백

- 카드 안쪽 여백: 위아래 `pad-y`(100), 좌우 `pad-x`(90). 글 폭은 `content-width`(900).
- 소제목 → 본문 `gap-lg`(72), 문단 사이 `gap-sm`(32), 흐름이 바뀌면 `gap-md`(48), 결론 앞 `gap-lg`(72).
- 표지는 제목·작성자·구분선·이미지·도입 사이를 모두 `gap-sm`으로 붙인다. 대표 이미지(900 × 675)를 쓰면 제목 두 줄, 도입 두 줄까지만 들어간다. 16:9 영상 캡처면 도입 세 줄까지 들어간다.
- 남는 공간은 카드 아래쪽에 비워 둔다. 글을 세로로 늘려 채우지 않는다. 예외는 생각 카드 하나로, `statement`가 가운데에 온다.

### 모서리·선·그림자

모서리는 모두 `radius-none`(직각). 원형은 프로필 사진(`radius-full`)뿐. 선은 표지 구분선(`line`, 1px)과 인용 박스 테두리(`ink`, 1px) 두 가지. 그림자, 그라데이션, 둥근 카드는 쓰지 않는다. (`.cn-mark`의 형광펜은 색 경계가 딱 끊기는 띠라서 그라데이션으로 보이지 않는다.)

## 이미지

- **영상·게시물 캡처** `Figure kind="capture"`: `content-width`(900) 폭, 원본 비율 그대로(`ratio`). 바로 아래에 `caption`으로 출처를 가운데 정렬: `[출처 - Youtube 조승연의 탐구생활]`.
- **대표 이미지** `Figure kind="hero"`: 표지에서만, 900 × 675.
- **곁들임 일러스트(밈·짤)** `Sticker`: 본문 카드 오른쪽 아래 귀퉁이에 세로형으로 작게(폭 190~330px), 글과 겹치지 않게. 카드당 최대 1장. 본문이 길어 아래 공간이 없으면 넣지 않는다.
- 이미지가 아직 없으면 `placeholder` 바탕 + `ink-muted` 글자로 "대표 이미지 900 × 675"처럼 크기를 적은 자리가 자동으로 생긴다.
- 작성자 프로필 사진은 Profile 에셋의 `avatar.png`를 `AuthorRow`의 `avatarSrc`로 넘긴다.

## 하지 말 것

- 카드마다 색이나 글꼴을 바꾸기, 본문 글자 크기를 카드마다 다르게 하기(22·23px 등).
- 한 카드에 소제목 두 개, 형광펜을 본문에 긋기.
- 글을 요약하거나 새 문장을 지어 넣기. 이 시스템은 사용자의 글을 그대로 옮긴다.

## 예시

```js
const C = window.CardNews;
h(C.Card, {
  label: "02 전역 직후",
  heading: "이걸 처음 생각했던 순간은\n전역한 직후이다",
  paragraphs: [
    "전역하고 나니 시간이 생겼다.\n다들 어디라도 다녀오라고 했다.",
    h(React.Fragment, null, "그런데 나는 계산부터 했다.\n",
      h(C.Strong, null, "겨우 그거 하나 다녀온다고 인생이 변하지도 않을 거고,"),
      "\n취업에 도움이 되지도 않을 거고."),
  ],
  conclusion: "그때의 나는 손해 보지 않는 법만 알았던 것 같다.",
});
```

미리보기의 문장들은 시스템을 보여 주기 위한 예시 글이다. 실제 카드에는 사용자의 글만 들어간다.
