# 컷노트 (계정 없이 쓰는 웹 버전)

편집자와 촬영자가 **링크 하나**로 의뢰서, 타임코드 수정 요청, 금요일 회의 안건을 함께 쓰는 페이지예요.
가입이나 로그인이 필요 없어요. 처음 들어올 때 이름과 역할(편집자/촬영자)만 한 번 적으면 돼요.

- 화면: `index.html` 파일 하나
- 저장소: 구글 파이어베이스(Firestore) 무료 요금제
- 주소: 깃허브 페이지(무료)

파이어베이스를 연결하기 전에는 **체험 모드**로 열려요. 체험 모드에서는 이 브라우저에만 저장되고, 다른 사람과 공유되지 않아요.

---

## 1. 파이어베이스 만들기 (10분, 한 번만)

1. https://console.firebase.google.com 에 구글 계정으로 들어가서 **프로젝트 추가**를 눌러요.
   이름은 `cutnote` 같은 걸로 정하고, 애널리틱스는 꺼도 돼요.
2. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**를 눌러요.
   위치는 `asia-northeast3 (서울)`, 모드는 **프로덕션 모드**를 골라요.
3. Firestore 화면의 **규칙** 탭을 열고, 이 폴더의 `firestore.rules` 내용을 통째로 붙여넣고 **게시**를 눌러요.
4. 프로젝트 개요 옆 톱니바퀴 → **프로젝트 설정** → 아래쪽 **내 앱**에서 웹 아이콘 `</>`을 눌러 앱을 등록해요.
   (호스팅 설정은 체크하지 않아도 돼요.)
5. 화면에 나오는 `const firebaseConfig = { ... }` 안의 값을 복사해요.
   이 값은 비밀번호가 아니에요. 웹페이지에 공개적으로 들어가도록 만들어진 값이에요.

## 2. 설정 값 넣기

`index.html` 맨 위쪽의 이 줄을 찾아서

```js
window.CUTNOTE_FIREBASE = null;
```

복사한 값으로 바꿔요.

```js
window.CUTNOTE_FIREBASE = {
  apiKey: "…",
  authDomain: "…",
  projectId: "…",
  storageBucket: "…",
  messagingSenderId: "…",
  appId: "…"
};
```

## 3. 깃허브 페이지로 공개하기

1. 깃허브 저장소의 **Settings → Pages**로 가요.
2. **Source**는 `Deploy from a branch`, **Branch**는 이 파일이 들어 있는 브랜치와 `/ (root)`를 골라 저장해요.
3. 1~2분 뒤 아래 주소로 열려요.
   `https://<깃허브아이디>.github.io/<저장소이름>/cutnote-web/`

## 4. 쓰는 법

1. 위 주소로 들어가서 **새 작업공간 만들기**를 눌러요. 주소 끝에 `?w=…`가 붙어요.
2. 오른쪽 위 **공유 링크 복사**를 눌러 촬영자에게 카톡으로 보내요.
3. 받은 사람은 링크를 열고 이름과 역할만 적으면 바로 같이 써요.
4. 기존 데이터가 있으면 **채널 · 업로드 → 백업 파일 불러오기**로 넣어요.

## 알아 둘 점

- **링크가 곧 열쇠예요.** 링크를 아는 사람은 누구나 보고 고칠 수 있어요. 필요한 사람에게만 보내 주세요.
- **이름은 확인하지 않아요.** 계정이 없어서 누가 적었는지는 각자 적은 이름을 믿어요.
- **백업**: 채널 · 업로드 탭에서 백업 파일을 내려받을 수 있어요. 한 달에 한 번쯤 받아 두면 안전해요.
- **무료 한도**: 파이어베이스 무료 요금제는 하루 읽기 5만 번, 쓰기 2만 번이에요. 두세 명이 쓰기에는 넉넉해요.
