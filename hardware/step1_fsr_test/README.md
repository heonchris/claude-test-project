# 1단계 · FSR-402 포화 테스트

## 이 폴더의 목적

FSR-402에 체중을 실었을 때 값이 최대치(1023)에 붙어버리는지 확인한다.
이 결과에 따라 이후 설계가 갈리므로 다음 단계로 넘어가기 전에 반드시 수행한다.

## 실행 방법

1. 아두이노 IDE에서 `step1_fsr_test` 폴더를 **폴더째로** 연다
   (`.ino` 파일은 같은 이름의 폴더 안에 있어야 열린다. 파일만 따로 옮기면
   IDE가 폴더를 새로 만들라고 묻는다 — 그냥 새 스케치에 코드를 붙여넣어도 된다)
2. [툴] → [보드] → `Arduino Uno`
   - **UNO R4**(Minima / WiFi)를 샀다면 [보드] → [보드 매니저]에서
     `Arduino UNO R4 Boards`를 먼저 설치해야 목록에 나온다
3. [툴] → [포트] → 연결된 포트
   - macOS: `/dev/cu.usbmodem…` (정품) 또는 `/dev/cu.wchusbserial…` (호환보드)
   - Windows: `COM3` 등
   - 어느 것인지 모르겠으면 USB를 뽑고 목록을 본 뒤 다시 꽂아 **새로 생긴 항목**을 고른다
4. 업로드(→) 버튼 → 하단에 `업로드 완료`가 뜨는지 확인
5. [툴] → [시리얼 플로터]

통신 속도는 **9600**이다. IDE 기본값과 같으므로 따로 바꿀 것이 없다.
글자가 깨져 보이면 플로터/모니터 속도가 9600인지 확인한다.

## 배선

```
5V  ──── ⓐ줄 ──── FSR 탭 ①
                        │
                   FSR 탭 ②
                        │
                   ⓑ줄 ─┼──────── A0     ← 여기 전압을 읽는다
                        │
                   10kΩ 저항
                        │
                   ⓒ줄 ──────────  GND
```

FSR 꼬리 끝의 은색 탭 2개는 간격이 2.54mm라 **브레드보드에 직접 꽂힌다.**
탭 두 개를 서로 다른 줄에 꽂고, 꼬리를 테이프로 고정한다.

푸쉬버튼(스프링) 터미널블럭은 둥근 전선 전용이라 FSR 탭에는 맞지 않는다.
터미널블럭을 꼭 쓰려면 나사식을 쓴다.

FSR과 저항 모두 방향이 없다. 어느 다리를 어디에 꽂아도 무관하다.

## 판정 순서

| 순서 | 동작 | 봐야 할 것 |
|---|---|---|
| 1 | 아무것도 안 올림 | 0에 가까운 낮은 값 |
| 2 | 손가락으로 살짝 | 올라감 |
| 3 | 손가락으로 꾹 | 더 올라감 |
| 4 | 뒤꿈치로 체중 절반 | 얼마까지 오르는가 |
| 5 | 체중 전부 싣기 | 1023에 붙는가 |
| 6 | 발을 올린 채 앞뒤로 무게 이동 | **그래프가 따라 움직이는가** |

4~5번은 센서 위에 딱딱한 조각(지름 1cm 정도)을 올리고 그 위를 밟는다.
맨발로 직접 누르면 힘이 한쪽에 쏠려 값이 불안정해진다.

**6번이 실제 판정 기준이다.** 5번에서 1023에 붙더라도 6번에서 그래프가
움직인다면 사용 가능하다. 이 제품이 알아내야 하는 것은 정확한 무게가 아니라
무게가 어디로 옮겨갔는가이기 때문이다.

## 결과별 대처

**A. 6번에서 그래프가 움직인다** → 합격. 2단계로 진행.

**B. 천장에 붙어 평평하다** → 1차: 저항을 낮춘다. ⓑ줄과 ⓒ줄 사이에
10kΩ을 나란히 더 꽂는다 (2개=5kΩ, 3개=3.3kΩ). 3개까지 시도 후 6번 재시험.

2차: 힘을 나눠 받게 만든다. 센서 양옆에 센서보다 살짝 두꺼운 스펀지를 두어
체중의 대부분을 스펀지가 받게 한다. **센서를 더 비싼 것으로 바꾸는 것보다
이 방법이 효과적이다** — FSR-406으로 바꿔도 측정 범위는 2kg 수준이라
결과가 크게 달라지지 않는다.

**C. 4~5번에서도 값이 거의 안 오른다** → 체중 문제가 아니라 배선 문제.
3번에서도 안 오르면 확실히 배선이다. FSR 탭 두 개가 같은 묶음에
꽂히지 않았는지, 점퍼선이 5V·A0·GND에 정확히 꽂혔는지 확인한다.
