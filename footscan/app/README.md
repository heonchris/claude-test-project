# footscan 체험판 앱 (휴대폰·브라우저 단독 실행)

`../engine` 의 파이썬 측정 엔진을 **브라우저가 알아듣는 언어(JavaScript)로 옮겨 심은
것**입니다. 서버도, 인터넷도, 앱 설치도 필요 없이 **휴대폰 안에서 직접 측정**합니다.

## 바로 써보기

```
footscan/app/app.html
```

이 파일 하나를 브라우저로 열기만 하면 됩니다. (더블클릭해도 됩니다)
사진 넣기 화면의 **「예시 사진으로 해보기」** 버튼을 누르면 발을 찍지 않고도 체험할 수 있습니다.

사진 칸을 누르면 **앱 안에서 카메라가 열립니다.** 화면에 A4 안내틀이 뜨고, 0.55초마다
`A4 인식 / 밝기 / 흔들림` 을 실시간으로 판정합니다. 카메라를 못 쓰는 환경(권한 거부,
미지원, `http://` 접속)에서는 자동으로 사진첩 선택으로 넘어갑니다.

> 카메라는 보안상 `https://` 또는 `localhost` 에서만 열립니다. 파일을 그냥 더블클릭해
> 여는 `file://` 방식에서는 사진첩 선택만 됩니다.

## 왜 라이브러리를 안 쓰나

영상처리는 보통 OpenCV.js 를 씁니다. 그런데 이 앱을 올려 두는 웹 환경의 보안 정책
(Content-Security-Policy)이 `unsafe-eval` 을 금지하는데, OpenCV.js 는 실행 중에 코드를
생성하는 방식(Emscripten embind)을 쓰기 때문에 **로드 자체가 실패합니다.** 실제로 그
보안 설정을 걸고 확인했습니다.

그래서 이 앱에 필요한 영상처리 기능만 직접 만들었습니다(`cvlite.js`, 668줄).
결과적으로 내려받는 용량 0MB, 완전 오프라인 동작, 메모리 사용 200MB→80MB 가 되었습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `app.html` | **완성본.** 아래 파일들을 하나로 합친 결과물 (빌드 산출물) |
| `app_ui.html` | 화면 뼈대와 디자인 (8개 화면, 다크 모드, 안전영역 대응) |
| `cvlite.js` | 직접 만든 영상처리 — 경계 검출, 윤곽 추적, 원근 펴기, 색공간 변환 등 |
| `engine2.js` | 측정 엔진 — `../engine/footscan/` 의 파이썬 파이프라인을 그대로 옮긴 것 |
| `app_logic.js` | 화면 동작 — 카메라, 사진 넣기, 품질 검사, 진행률, 결과, 이력, 공유 |
| `tests/` | 실제 브라우저를 띄워 확인하는 자동 검사 6종 (`tests/README.md`) |
| `samples.js` | 예시 사진 (자동 생성물 — `make_samples.py` 가 만듭니다) |
| `boot.html` | 시작 처리 |
| `samples/` | 예시 사진 원본 |
| `make_samples.py` | `samples/*.jpg` → `samples.js` 변환 |
| `build.sh` | 위 조각들을 `app.html` 하나로 합침 |

## 고치는 방법

`app.html` 을 직접 고치지 마세요. 조각 파일을 고친 뒤 다시 합칩니다.

```sh
sh build.sh
```

측정 기준값은 `engine2.js` 맨 위 `CFG` 에 모여 있습니다. 파이썬 쪽
`../engine/footscan/config.py` 와 짝을 이루므로, **한쪽만 고치면 두 엔진의 답이
달라집니다.** 둘 다 고치세요.

## 파이썬 엔진과의 차이

| 항목 | 파이썬 엔진 | 이 앱 |
|---|---|---|
| 계산 정밀도 | 1픽셀 = 0.1mm | 1픽셀 = 0.2mm (속도 때문) |
| 발 길이 오차 | 0.60mm | 1.00mm |
| 발볼 너비 오차 | 0.10mm | 0.50mm |
| 아치 높이 오차 | 0.20mm | 0.50mm |
| 발가락 형태 / 아치 등급 | 7표본 전부 일치 | 7표본 전부 일치 |

합격 기준(길이·발볼 ±3mm, 아치 ±4mm)은 양쪽 모두 통과합니다.

빈틈 메우기(morphology)에 파이썬은 타원 커널, 이 앱은 정사각 커널을 씁니다.
정사각이 대각선 틈을 약 40% 더 메우기 때문에, 같은 결과를 내려면 이 앱의
`TOP_MORPH_CLOSE_MM` 이 파이썬(1.5)보다 작아야 합니다(0.9). 값을 맞추려 하지 마세요.

## 아직 못한 것

- **실제 안드로이드 기기에서 돌려보지 못했습니다.** PC 브라우저를 폰 화면 크기로
  띄워서만 확인했습니다. 실기기에서는 측정 시간이 2~3배 걸릴 수 있습니다.
- 카메라 화면은 **가짜 영상으로만** 확인했습니다. 실제 폰 카메라의 초점·회전·화질은
  실기기에서 확인해야 합니다.
- 사진 품질 검사 기준과 아치 등급 경계값은 **합성 사진으로만 보정**되어 있습니다.
