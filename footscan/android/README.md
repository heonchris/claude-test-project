# 안드로이드 앱 (APK)

`../app/app.html` 을 그대로 감싼 안드로이드 앱입니다. 측정은 전부 웹 쪽 코드가
하고, 이 앱은 **카메라가 열리게 해 주는 껍데기** 역할만 합니다.
아이폰 앱(`../ios`)과 완전히 같은 화면·같은 계산입니다.

## 설치하기 — 폰에서 3단계

1. **`발스캔.apk`** 파일을 안드로이드 폰으로 보냅니다
   (카카오톡 「나에게 보내기」, 메일, USB, 구글 드라이브 아무거나)
2. 폰에서 그 파일을 누릅니다
3. **「이 출처의 앱 설치」를 허용** 하겠냐고 물으면 허용 → 설치

> 앱스토어(플레이스토어)를 거치지 않은 앱이라 경고가 뜹니다. 정상입니다.
> 설정 > 앱 > 특별한 접근 > 알 수 없는 앱 설치 에서도 켤 수 있습니다.

설치하면 홈 화면에 **「발 스캔」** 아이콘이 생깁니다.

## 처음 켰을 때

**카메라 권한**을 물어봅니다. 허용하면 앱 안에서 바로 찍을 수 있고,
거부해도 **사진첩 사진으로는 그대로 측정됩니다.**

앱 첫 화면 맨 아래 **「기기 진단」 → 자체 시험 실행** 을 눌러
**249.4mm 근처**가 나오면 이 폰에서 계산이 정상입니다.

## 직접 만들려면

```sh
cd footscan/android
sh build_apk.sh
```

필요한 것: 자바 17 이상, 안드로이드 SDK(`ANDROID_HOME` 또는 `local.properties`).
안드로이드 스튜디오를 설치했다면 이 폴더를 열어 ▶︎ 를 눌러도 됩니다.

결과물: `app/build/outputs/apk/debug/app-debug.apk`

## 구조

| 파일 | 하는 일 |
|---|---|
| `app/src/main/java/.../MainActivity.java` | 화면 전체를 채우는 웹뷰 + 카메라 권한 + 사진첩 열기 |
| `app/src/main/java/.../LocalServer.java` | 127.0.0.1 에만 붙는 아주 작은 웹 서버 |
| `app/src/main/assets/web/index.html` | `../app/app.html` 복사본 (`build_apk.sh` 가 넣습니다) |
| `app/src/main/AndroidManifest.xml` | 카메라 권한, 세로 고정, 앱 이름 |

### 왜 앱 안에 서버를 띄우나

브라우저는 **"안전한 주소"에서만 카메라를 열어** 줍니다. 앱 안의 파일을 그냥 여는
`file://` 방식은 안전한 주소로 쳐 주지 않습니다. `127.0.0.1`(내 폰 자신)은 어디서나
안전한 주소로 인정되므로, 앱 안에 작은 서버를 띄우고 그 주소로 화면을 엽니다.
바깥에서는 접속할 수 없습니다.

서버가 뜨지 않으면 `file://` 로 넘어가 **측정은 그대로 되고 카메라만** 잠깁니다.

### 라이브러리를 하나도 안 씁니다

안드로이드에 들어 있는 것만으로 만들었습니다(`dependencies { }` 가 비어 있습니다).
그래서 APK 가 **330KB** 밖에 안 되고, 그중 대부분이 웹 화면입니다.

## 확인한 것 / 못 한 것

- ✅ 빌드 성공, 디버그 서명 정상, 앱 이름·권한·화면 방향 확인
- ✅ APK 안의 웹 화면이 `../app/app.html` 과 **바이트 단위로 동일**
- ✅ Android Lint 오류 0건
- ❌ **실제 안드로이드 기기나 에뮬레이터에서 실행해 보지 못했습니다.**
  (이 작업 환경에 가상화(KVM)가 없어 에뮬레이터를 띄울 수 없습니다)
  설치 후 문제가 있으면 「기기 진단」 결과를 보내 주세요.
