먼저 읽어주세요

A4 종이 한 장으로 발 크기를 재는 기능입니다. 이 폴더 안에 지금까지 만든 것이 전부 들어 있습니다.

딱 하나만 하신다면

1_앱 / 발스캔_앱.html 파일을 더블클릭해 주세요.

설치할 것도, 인터넷도 필요 없습니다. 브라우저가 열리고 바로 앱이 뜹니다. 사진 넣기 화면의 「예시 사진으로 해보기」를 누르면 발을 찍지 않고도 측정 결과를 보실 수 있습니다.

폴더 안내

폴더 / 파일무엇인가누가 보나
1_앱 / 발스캔_앱.html 완성된 앱. 더블클릭하면 바로 실행됩니다. 이 파일 하나가 앱의 전부입니다. 대표님
2_보고서 / 개발보고서.html 지금까지의 개발 내용 전체. 정확도, 안전장치, 남은 위험, 결정이 필요한 것. 대표님
1_앱 / 원본코드 / 앱을 만든 조각 파일들과 자동 검사. 앱을 고치려면 여기를 봅니다. 개발자
3_원본엔진_파이썬 / 정확도의 기준이 되는 원본 계산 엔진. 앱은 이것을 옮겨 심은 것입니다. 개발자

휴대폰에서 써보시려면

앱 파일 하나만 폰에 있으면 됩니다. 가장 쉬운 방법 두 가지입니다.

  1. 카카오톡 「나에게 보내기」 — 발스캔_앱.html 을 나에게 보낸 뒤, 폰에서 그 파일을 눌러 크롬으로 열기를 선택합니다.
  2. 이미 받으신 인터넷 주소로 열기 — 가장 확실한 방법입니다. 담당자가 보내드린 체험판 링크를 폰 크롬에서 열면 됩니다.
참고 — 카메라는 인터넷 주소로 열었을 때만 켜집니다. 파일을 직접 열면(①번 방법) 보안 규칙 때문에 카메라가 열리지 않고 사진첩에서 고르기만 됩니다. 측정 자체는 똑같이 됩니다. 카메라까지 써보시려면 ②번 방법으로 열어 주세요.

직접 발을 재보시려면

  1. A4 용지 한 장을 단단하고 평평한 바닥에 놓습니다. (카펫 ✕)
  2. 불을 켜고, 짙은 그림자가 지지 않게 합니다.
  3. 맨발로 종이 위에 올라서서, 체중을 실어 똑바로 섭니다.
  4. 종이 네 모서리가 모두 보이게 위에서 한 장 찍습니다. (높이 40~60cm)
  5. (선택) 발 안쪽 아치가 보이게 옆에서 한 장 더 찍습니다.
  6. 앱에서 그 사진을 넣고 측정하기를 누릅니다.
사진은 폰 밖으로 나가지 않습니다. 계산이 전부 폰 안에서 이뤄지므로 어디로도 전송되지 않고, 측정이 끝나면 사라집니다.
