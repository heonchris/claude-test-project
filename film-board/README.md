# 촬영 보드

영화 촬영 팀(연출·제작·촬영·소품)이 일정, 씬별 촬영 기록, 소품, 장비, 공지와 변경 사항을 한곳에서 공유하는 웹페이지예요.
팀원은 **링크만 있으면 로그인 없이** 보고 쓸 수 있어요. 처음 열 때 이름만 적으면 돼요.

- 데이터는 내 구글 드라이브의 구글 시트 한 장에 저장돼요.
- 사진과 파일은 내 드라이브의 `촬영 보드 업로드` 폴더에 저장돼요.
- 다른 사람이 고친 내용은 15초 안에 모든 화면에 반영돼요.

## 기능

| 탭 | 하는 일 | 주로 쓰는 팀 |
|---|---|---|
| 홈 | 다음 촬영(D-day, 콜타임, 장소, 씬, 식사), 확인 안 한 공지, 씬·소품·장비 진행률 | 전체 |
| 일정 | 회차별 콜타임·장소·씬, **시간대별 장소·씬**, **식사(식당·배달·인원·담당·예약)**, 그날 찍은 씬 | 제작 |
| 씬 | 씬 목록(장소, 실내/실외, 시간대, 등장인물, 필요 소품), 상태, **실제 촬영일·장소·기록** | 제작·연출 |
| 소품 | 공간별 소품 리스트(조달 방법, 담당, 상태, 사진) + **무드보드**(조안스테이 방 레퍼런스 이미지) | 소품 |
| 장비 | 분류별 장비 체크리스트, 출발 전 체크, 다음 회차용 체크 해제 | 촬영·제작 |
| 공지·변경 | 공지·결정·변경 글, 파일 첨부, **확인했어요** 표시. 일정·시간대·식사를 고치면 무엇이 바뀌었는지 변경 글이 자동으로 올라옴 | 전체 |

## 설치 (한 번, 5분)

1. [script.google.com](https://script.google.com) 에서 **새 프로젝트**를 만들고 이름을 `촬영 보드`로 바꿔요.
2. 왼쪽 `Code.gs`의 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 붙여 넣어요.
3. 왼쪽 파일 목록의 **＋ → HTML**을 눌러 파일 이름을 `index`로 만들고, 이 폴더의 `index.html` 내용을 붙여 넣어요.
4. 저장(⌘S / Ctrl+S)한 뒤, 위쪽 함수 선택에서 `setup`을 고르고 **실행**을 눌러요.
   - 권한 확인 창이 뜨면 내 계정을 고르고 **고급 → 촬영 보드(으)로 이동(안전하지 않음) → 허용**을 눌러요. 내가 만든 스크립트라서 뜨는 경고예요.
   - 실행 로그에 `완료. 시트: https://...`가 나오면 시트와 업로드 폴더가 만들어지고, 작품 제목과 즉흥영화 제안 공지만 들어가요. 일정·씬·소품·장비는 비어 있어서, 방향이 정해지면 페이지에서 채우면 돼요.
   - 초기 데이터를 고친 뒤 처음부터 다시 넣고 싶으면 `resetAndSetup`을 실행하세요. **시트의 모든 내용이 지워지니 팀원이 쓰기 전에만** 쓰세요.
5. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**을 골라요.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르면 나오는 `https://script.google.com/macros/s/.../exec` 링크를 팀 단톡방에 공유해요.

### 코드를 고친 뒤 반영하기

**배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**를 누르면 같은 링크로 바뀐 내용이 나가요.

### 팀 비밀번호 걸기 (선택)

링크를 아는 사람은 누구나 글을 쓸 수 있어요. 링크가 밖으로 퍼질 걱정이 되면 `Code.gs`의 `setPasscode` 함수 안 `'여기에-비밀번호'`를 원하는 비밀번호로 바꾸고 `setPasscode`를 한 번 실행하세요. 팀원은 처음 열 때 비밀번호를 한 번 입력하면 돼요.

## 문서에서 씬 가져오기

씬 탭의 **「문서에서 가져오기」**를 누르면 씬을 하나씩 입력하지 않고 한 번에 채울 수 있어요.

- **구글 문서 링크**를 붙여 넣고 「불러오기」를 누르거나, 대본을 **직접 붙여 넣어요**. 문서에 탭이 여러 개면 씬이 있는 탭을 자동으로 골라요.
- `S#1 옆동네 (밤)`처럼 씬 머리가 있으면 씬마다 **씬 번호, 장소, 실내/실외, 시간대, 등장인물(대사 앞 이름), 첫 지문(요약)**을 채워요. `INSERT:` 줄은 메모로 들어가요. `씬 1.`, `#1` 형식도 알아봐요.
- 씬 번호 없이 핵심 사건이나 스토리보드를 줄마다 적었다면 **「한 줄 = 씬 하나」**를 골라요.
- 올리기 전에 목록을 보고 고를 수 있어요. **이미 있는 씬 번호는 내용만 갱신**하고, 상태·촬영 예정일·촬영 기록·소품은 그대로 둬요.
- 다 올리면 공지·변경 탭에 "씬 N개를 문서에서 가져왔어요" 글이 자동으로 올라가요.

**처음 한 번 해야 할 것:** 이 기능이 들어간 `Code.gs`로 바꾼 뒤에는 편집기에서 **`setup`을 한 번 다시 실행**해서 「Google 문서 보기」 권한을 허용해 주세요(데이터는 지워지지 않아요). 그다음 「새 버전」으로 배포하면 돼요.
보드를 배포한 구글 계정이 볼 수 있는 문서만 불러올 수 있어요. 안 열리면 문서 내용을 복사해서 붙여 넣으면 돼요.

## 알아 둘 점

- 사진은 올릴 때 자동으로 줄여서(긴 변 1600px) 올라가요. 다른 파일은 25MB까지 올릴 수 있어요.
- 이름은 각자 기기에만 저장돼요. 같은 사람이 폰과 노트북에서 쓰면 두 곳 모두 같은 이름을 적어 주세요.
- 삭제한 항목도 시트에는 `deleted = TRUE`로 남아 있어서, 실수로 지웠을 때 시트에서 `FALSE`로 바꾸면 되살아나요.
- 시트를 직접 고쳐도 돼요. 다만 `data` 칸은 JSON 형식이라 페이지에서 고치는 편이 안전해요.

## 개발할 때 테스트

`test/`에는 Apps Script를 흉내 내는 환경(`gas-emulator.js`)과 브라우저 시험(`e2e.js`)이 있어요. 실제 `Code.gs`와 `index.html`을 그대로 써서 두 사람이 동시에 쓰는 상황, 사진 업로드, 비밀번호까지 확인해요.

```bash
npm i -D playwright   # 처음 한 번
node film-board/test/e2e.js        # 서버+화면 전체 시험
node film-board/test/parse.test.js # 대본 분석기 시험
python3 film-board/tools/build-preview.py 미리보기.html  # 미리보기 페이지 만들기
```
