# 족저압 스마트 인솔 — 앱 프로토타입

발바닥 압력 16채널을 실시간으로 시각화하고 세트 종료 시 자세 피드백
리포트를 생성하는 앱의 **동작하는 프로토타입**입니다.

## 여는 방법

`index.html` 을 브라우저로 더블클릭하면 끝입니다.
빌드도, 설치도, 서버도 필요 없습니다.

- **PC** — 휴대폰 기기 프레임 안에서 앱처럼 보입니다
- **휴대폰** — 프레임 없이 화면 전체를 채웁니다

## 5분 안에 확인하는 법

1. **설정** 탭 → **좌우 불균형** 선택
2. **측정** 탭 → 측정 시작 → 5초 두고 → 측정 정지
3. 리포트가 올라옵니다 (좌우 36:64, "좌우 편차 큼")
4. 설정에서 **뒤꿈치 들림** 으로 바꿔 한 번 더
5. **기록** 탭에 두 세트가 쌓여 있습니다

## 먼저 읽을 문서

| 문서 | 내용 |
|---|---|
| **[DATA_CONTRACT.md](DATA_CONTRACT.md)** | 센서 ↔ 앱 데이터 규격. **실제 계약 지점입니다** |
| **[HANDOFF.md](HANDOFF.md)** | 개발자 인수인계 노트. 무엇이 진짜이고 무엇이 가짜인지 |

## 파일 구조

```
index.html          화면 구조
css/app.css         스타일 (색은 전부 CSS 변수)
js/
  01-config.js      ★ 센서 배치·판정 기준·색상 — 튜닝은 전부 여기서
  02-sensor.js      ★ 데이터 소스 — 실제 센서로 갈아끼우는 지점
  03-metrics.js     무게중심·좌우/전후 비율 계산 (순수 함수)
  04-heatmap.js     발 외곽선 + IDW 보간 렌더
  05-chart.js       압력 추이 그래프
  06-report.js      세트 판정 로직
  07-app.js         화면 배선
```

★ 표시된 두 파일만 알면 대부분의 수정이 가능합니다.

## 실제 센서를 붙이려면

`js/02-sensor.js` 의 `connectBLE()` 하나만 구현하면 됩니다.
패킷 규격은 DATA_CONTRACT.md 를 따르세요.
구현 후 `js/07-app.js` 의 루프에서 `S.step(elapsed)` 한 줄을 지우면 끝입니다.

## 중요

이것은 **시뮬레이션 데이터로 도는 UI 프로토타입**입니다.
실제 센서 연동, 백엔드, 데이터베이스, 크로스플랫폼 빌드는 들어 있지 않습니다.
자세한 범위는 HANDOFF.md 를 보세요.
