# 폰트

| 파일 | 용도 | 라이선스 |
|---|---|---|
| `Pretendard-Regular.otf` | 본문 | SIL Open Font License 1.1 (orioncactus/pretendard) |
| `Pretendard-Bold.otf` | 본문 강조 | SIL Open Font License 1.1 |
| `Cafe24Ssurround.ttf` | 제목·숫자 | Cafe24 무료 폰트 (개인·상업 이용 및 재배포 허용) |

두 폰트 모두 무료로 배포되는 한글 폰트입니다.
폰트를 바꾸고 싶으면 이 폴더에 `.ttf`/`.otf` 파일을 넣고 `theme/typography.ts`의
`FONT_ASSETS`만 수정하면 됩니다. (`.woff`, `.woff2`는 React Native에서 동작하지 않습니다.)
